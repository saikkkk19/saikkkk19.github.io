# saikkkk19.github.io

Personal portfolio of **Saikishore Sridhar** — machine-learning engineer in
neurotechnology (EEG, MRI, fNIRS).

Live site: **https://saikkkk19.github.io**

A single self-contained `index.html` (inline CSS + JS, no build step, no
dependencies). The hero renders a live multi-channel EEG-style waveform on a
`<canvas>`, and the page supports light/dark themes with a toggle.
